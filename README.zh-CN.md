> 独立、非官方社区项目，与香港中文大学（深圳）无隶属关系，未获其背书。

从能帮助一个同学的项目开始。欢迎新作品，不设 Star 门槛；学校关联须有公开依据，不推断个人身份。

首批 **16 个项目**，数据核查于 **2026-11-01**。Star 是当日快照；活跃度按默认分支最近提交计算，分为 180 天内、181–365 天内和超过一年。这里的“近期”不代表持续维护承诺。
