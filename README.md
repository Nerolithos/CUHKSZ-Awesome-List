A community-curated list of projects, developer tools, learning resources, and useful links related to The Chinese University of Hong Kong, Shenzhen.

**CUHKSZ · CUHK-Shenzhen · CUHK(SZ) · LGU · 龙大 · 港中深**

> An independent, unofficial community project. Not affiliated with or endorsed by CUHK-Shenzhen.

Start with something that helps a fellow student. New projects are welcome, with no star threshold. School connections require public evidence; personal identities are never inferred.

The initial **16 projects** were checked on **2026-11-01**. Stars are a dated snapshot. Activity uses the latest default-branch commit: within 180 days, 181–365 days, or over a year. Recent activity is not a promise of ongoing support.

**Licensing:** This index includes open-source software and public resources. “License unclear” means explicit reuse permission has not been confirmed. Datasets, model weights, and third-party materials may carry separate terms.

See the [selection audit](docs/SELECTION.md), [contribution guide](CONTRIBUTING.md), and [author outreach guide](docs/OUTREACH.md).

Primary language follows GitHub repository language detection (checked on 2026-11-12), rather than the full technology stack. Repositories without a detected language are labeled “Not detected”.
